# 老板痛点分析

## 核心判断

老板真正要解决的不是“有没有数据”，而是：

> 每天接收到大量投研和推荐信息，但这些信息太散、太吵、不可验证，最后很难变成可执行的投资判断。

所以这个项目的本质不是做一个消息展示工具，也不是替老板炒股，而是把老板每天依赖的信息流和判断过程数字化、结构化、可复盘。

更准确的闭环是：

```text
投研消息 -> 信息归类 -> 观点链沉淀 -> 推荐人/主题评价 -> 决策辅助与复盘
```

## 1. 信息过载

微信个人、微信群、冈底斯、阿尔法派里会持续推送各种内容：

1. 个股推荐。
2. 行业观点。
3. 研报摘要。
4. 策略会、调研、活动通知。
5. 工具服务介绍。
6. 私人消息和无关噪声。

老板不是缺信息，而是信息太多、格式太乱。

关键问题：

1. 哪些是真正有交易价值的推荐？
2. 哪些只是研究观点或活动通知？
3. 哪些应该直接过滤？

## 2. 推荐不可比较

不同推荐人的表达方式不统一，例如：

1. 重点关注。
2. 继续推荐。
3. 长逻辑不变。
4. 弹性大。
5. 低开可吸。
6. 短线看 10 个点。

这些话在聊天里能看懂，但不能直接比较、统计和回测。

关键问题：

1. 推荐动作是什么：买入、关注、加仓、卖出，还是只是研究观点？
2. 推荐强度有多高？
3. 对应的是日内、短线、波段还是中线？
4. 目标收益和风险边界在哪里？

## 3. 不知道谁靠谱

老板原话里最关键的是：

> 找到这些推荐的这个人的一些规律，从而进行一些交易，谁的胜率高，然后进行交易。

这说明核心目标不是简单看消息，而是识别推荐人的 alpha，并把老板对这些推荐人的判断过程沉淀下来。

关键问题：

1. 谁历史胜率高？
2. 谁只是经常喊，但效果不好？
3. 谁适合短线，谁适合中线？
4. 谁在某些板块特别准？
5. 谁的推荐收益高但回撤也大？

## 4. 缺少反馈闭环

现在一条推荐消息发出来，看完就过去了。几天后涨了还是跌了，通常没有系统性记录。

关键问题：

1. 推荐后 1日、3日、5日、10日、20日表现如何？
2. 有没有跑赢指数或所属板块？
3. 有没有先跌很多再上涨？
4. 推荐人的长期表现是否稳定？

没有反馈闭环，就只能凭印象判断谁厉害。

## 5. 前后观点变化没有被记录

真正有交易价值的往往不是单条消息，而是同一个推荐人围绕同一标的或主题的观点链：

1. 首次提出。
2. 持续强化。
3. 补充证据。
4. 提醒风险。
5. 观点修正。
6. 观点反转。
7. 逻辑兑现或逻辑破坏。

这些前后变化里包含老板的专业判断空间。系统需要先把观点链记录下来，后续再把老板的经验规则沉淀成模型。

## 6. 从信息到交易动作中间缺流程

即使看到一条“推荐 XX 股票”，也还需要继续判断：

1. 这只股票是不是已经涨很多了？
2. 这是短线机会还是中线逻辑？
3. 有没有多人、多群、多来源共振？
4. 推荐人历史表现怎么样？
5. 当前风险大不大？
6. 应该放进观察池、自选池，还是交易池？

这中间缺一套标准流程，把消息变成可执行判断。

## 7. 项目边界

老板可能会说“进行交易”，但第一阶段不建议直接做自动交易。

更合理的边界是：

1. 先做信息流和判断过程数字化。
2. 先证明数据清洗、推荐识别、观点链沉淀、回测评价有效。
3. 再讨论交易信号、仓位、风控和是否对接真实交易。

## 一句话总结

把老板每天依赖的信息流和判断过程数字化、结构化、可复盘，再逐步沉淀成可验证的推荐人 alpha 和交易辅助系统。
